Catatan wireframe

Perilaku komponen

  1. Judul berupa kesimpulan berangka, dibuat otomatis dari data (panduan UI §5). Kalimat berubah sesuai kondisi, mis. "Semua proyek sesuai rencana".
  2. KPI tile dapat diklik sebagai filter tabel portofolio. Status selalu ikon + teks + warna (PRD §8.2). Kepatuhan update dari view v_kepatuhan_update.
  3. Perlu keputusan Anda hanya menampilkan permintaan yang ditujukan ke pengguna yang login (direksi/kabag). Tombol Tanggapi membuka panel tanggapan; status Dipenuhi/Ditolak wajib disertai teks (FR-50..52, view v_dukungan_terbuka).
  4. Pemeriksaan otomatis adalah pengganti review manual atas kualitas laporan: update belum diajukan, re-baseline tertunda, aksi lewat target, proyek tanpa data, rutin terlambat. Setiap baris dapat diklik ke daftarnya.
  5. Tabel portofolio dari view v_proyek_kesehatan. % rencana dihitung dari baseline aktif, bukan rencana yang sedang diedit. Penanda ↓ = status diperburuk manual oleh PIC (override); status tidak pernah bisa diperbaiki manual.
  6. Gantt ringkas menampilkan baseline vs aktual dengan garis "hari ini". Detail per aktivitas (Target/Real per minggu seperti slide lama) ada di halaman detail proyek.
  7. Pekerjaan rutin (LM Triwulanan, laporan bulanan ke Holding) dipisah dari proyek supaya tidak mencemari % progres portofolio (FR-15).
